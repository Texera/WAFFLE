# KNIME study starters

Download the starter for your assigned workflow.

- [Workflow A](https://raw.githubusercontent.com/Texera/WAFFLE/main/experiments/user_study/starters/knime/KNIME-Workflow-A-starter.knwf)
- [Workflow B](https://raw.githubusercontent.com/Texera/WAFFLE/main/experiments/user_study/starters/knime/KNIME-Workflow-B-starter.knwf)

Import the `.knwf` archive into KNIME Local space. Each archive contains its input
data and starts with one iteration at K=2. Use the organizer's task instructions
and keep the prepared calculation unchanged. Press Ctrl+S before each export.

These are the unchanged portable starters from the November 15, 2026 rehearsal
of the 35-minute study, checked with KNIME 5.5.3 and its Java Snippet nodes.
Complete installation, import and export practice before starting the timer.
