# Section 7 data index

This index follows the Section 7 manuscript at Overleaf Git revision `90addfe`. From the repository root, run `python tools/verify_results.py` to check the saved measurements and `python tools/make_figures.py` to render the nine external figure PDFs. Figures 21 and 22 are drawn in the paper’s LaTeX source.
